# EasyScript.io v0.7.0 — Clean Luau Tutorials + Eight Ultra Tools

[Launch EasyScript.io](https://sillydev2026.github.io/EasyScript.io/) · [Repository](https://github.com/SillyDev2026/EasyScript.io)

EasyScript is a static, browser-based Roblox Luau and JavaScript visual scripting builder with **128 block types**, a 24-file local project workspace, source previews, templates and JSON backups.

## Clean code generation — v0.7

The leaderstats block now generates straightforward Roblox tutorial-style code, rather than variables based on internal block IDs:

~~~lua
local Players = game:GetService("Players")

Players.PlayerAdded:Connect(function(player)
    local leaderstats = Instance.new("Folder")
    leaderstats.Name = "leaderstats"
    leaderstats.Parent = player

    local coins = Instance.new("IntValue")
    coins.Name = "Coins"
    coins.Value = 0
    coins.Parent = leaderstats
end)
~~~

The new **Player DataStore + Leaderstats** template:
- Declares Players, DataStoreService and the selected DataStore **once at the top of the Script**.
- Uses concise protected GetAsync calls and properly indented error handling inside PlayerAdded.
- Names locals clearly, e.g. success, savedCoins, leaderstats and coins.
- Reuses the folder when multiple leaderstat blocks are inside the same event.
- Avoids autogenerated ID suffixes and repeated service declarations.
- Keeps assignments on the same line as their values.

There are **two separate templates**: simple leaderstats (no persistence) and leaderstats with DataStore read. The latter does *not* save; add a server-side saving strategy, proper retries, budgets and test coverage before production use.

## Globals are now script-local variables in Luau

The original global blocks are now called **Set script variable**, **Read script variable**, **Increase script variable**, and **Clear script variable**.

These generate **ordinary locals scoped to the generated Script**, such as:

~~~lua
local Coins = 0
Coins = (Coins or 0) + (1)
Coins = Coins or 0
~~~

No Luau shared-environment global table is used. Locals are **not automatically shared among separate Scripts, ModuleScripts, servers or clients**. For real sharing, use ModuleScripts and RemoteEvents as appropriate. JavaScript still uses globalThis for its own browser-runtime global blocks.

## Responsive workspace sizing

On wide screens the default proportions are **19% block palette / approximately 52% editor / 29% source output**, with smaller adjustments for column gaps. Sliders adjust widths; tablets use two columns with source output below; narrow phones and folded devices use separate Blocks / Workspace / Code tabs. Settings persist locally and can be reset.

## Five new Ultra+ tools (eight total)

1. **Code Style Studio:** Preview, copy or download source with 2-, 4- or 8-space indentation, show/hide header and readable/compact blank lines.
2. **Variable Explorer:** Inspect names, local/global semantics and approximate declarations, writes and references; jump to a block.
3. **Service Explorer:** List Roblox services used in generated code and reference counts.
4. **Runtime Checklist:** Check server Script/LocalScript/ModuleScript context, risky networking/DataStore operations and invalid blocks. Advisory, not a certification.
5. **Version Compare:** Compare the current generated script with a locally saved My Projects snapshot, highlighting changed source lines.

Existing Ultra tools remain: **Roblox System Builder**, **Structure Map**, and **Script Health Audit**.

## Other features retained

- 128 blocks including Roblox Instances, Players, Humanoids, Attributes, RemoteEvents, DataStores, UI, math, vectors and JavaScript DOM/browser APIs.
- 20 editable starter templates and packs.
- Full-source copying with selectable fallback for browsers without clipboard permissions.

- Undo/redo, nested editable blocks, collapse/expand, source highlighting, import/export and local autosave.
- Multi-file Explorer supporting up to 24 scripts; clipboard reusable block trees between files.

The GitHub Actions CI checks JavaScript syntax and regression suites, including exact tutorial-output assertions, indentation, scopes, local initialization ordering, Roblox service hoisting, JS syntax, version comparisons and the Ultra+ analyzers.

## Important limitations

- This is **source generation, not a Roblox compiler, runtime or FPS profiler**. Roblox APIs require correct Script/LocalScript placement and Roblox Studio testing.
- User-entered raw expressions must still be reviewed; diagnostics are limited.
- DataStore starter examples are educational and do not include a complete, durable saving strategy.
- RemoteEvent handlers must validate client-supplied data and permissions.
- Code Style Studio modifies presentation/export indentation, not the actual block structure.
- Version Compare uses a simple bounded source-line comparison, not a semantic AST diff.
- Project backups and snapshots are stored in browser localStorage; export files regularly.
- No online accounts, cloud synchronization or live collaboration are included.
- The UI uses nested drag/drop block cards; it is not yet a fully socket-connected block system.
- No redistribution license has been selected.
